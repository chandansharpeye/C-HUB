C-HUB 2.0 — RELEASE NOTES
========================

New: School Study Library for Classes 5–10.
- Class and subject selector
- Official SCERT Odisha / BSE Odisha textbook-resource links
- Illustrated study-card layout
- Original starter practice questions and answer reveals
- Local PDF/image textbook preview
- Personal revision cards saved on this device
- Export revision cards as JSON
- Hindi/Odia/English UI for the new library
- PWA service worker cache bumped to v12

PUBLISH
-------
1. Back up the current GitHub repository.
2. Upload ALL files in this folder to the repository ROOT, replacing matching files.
3. Commit to the branch used by GitHub Pages.
4. Wait for deployment, refresh the site, and close/reopen the installed app.

IMPORTANT
---------
Official links may change and textbook editions vary by year. Starter questions are original practice aids, not official answer keys. Full verified textbook answers for every chapter are not bundled. The existing site's Hindi/Odia translation dictionary is incomplete outside the new library.
